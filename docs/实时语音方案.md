# 双视频链路

| 模式 | 上行输入 | 回答与画面 | 浏览器媒体 |
| --- | --- | --- | --- |
| 千问 + Vidu 组件版 | AudioWorklet 采集 16 kHz 单声道 PCM，经本机 WebSocket 转给千问 | 千问回复的 24 kHz PCM 转给 Vidu，驱动人物画面 | 订阅 Vidu 托管 RTC 的音视频 |
| Vidu 完整实时版 | 浏览器通过阿里 RTC 发布麦克风音轨 | Vidu 完成对话、语音生成和渲染 | 订阅同一个房间中的数字人 |

本机后端调用 Vidu 创建接口，等待 WebSocket 的初始化回执，再发给浏览器临时入房凭证。收到浏览器的首帧确认后，组合链路启动千问会话。完整实时版使用 Vidu 的对话栈，网页可以通过文字信令补充一句话。 [Vidu 组件版](https://platform.vidu.cn/vidu-stream/doc/s2-avatar/component/parameters) · [Vidu 实时版](https://platform.vidu.cn/vidu-stream/doc/s2-avatar/realtime/parameters)

组合链路按 20 ms 转发回复音频。插话或点停止时，丢弃待发送的千问语音，并向 Vidu 发出中断信令。挂断时，本机关闭云端会话，浏览器退出房间并释放麦克风。 [千问实时接口](https://help.aliyun.com/zh/model-studio/qwen-audio-realtime-user-guides)
